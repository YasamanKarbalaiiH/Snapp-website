# Snapp Website

A responsive website inspired by Snapp, built to practice frontend layout, responsive design, and Tailwind CSS.

## Overview

This project is a frontend practice project focused on recreating the structure and visual layout of a modern web page using HTML and Tailwind CSS.

The project was built to improve skills in responsive layouts, styling, and translating a visual design into a functional webpage.

## Features

* Responsive layout
* Modern web page structure
* Mobile-friendly design
* Tailwind CSS styling
* Reusable utility classes

## Technologies

* HTML
* Tailwind CSS

## Purpose

This project was created as a frontend practice project to strengthen skills in:

* HTML structure
* CSS styling
* Tailwind CSS
* Responsive web design
* UI implementation
